# مرکز خدمات مالی پورتال ورزش

این پوشه، هسته و داشبورد شبکه مراکز خدمات مالی را نگهداری می‌کند.

## اجزا
- `index.html`: نمای مرکزی و تجمیع گزارش فدراسیون‌ها
- `finance.css`: سبک مشترک
- `finance.js`: نمای مدیریتی و ورود بسته‌های داده
- `squash/`: نخستین مرکز مستقل؛ پایلوت فدراسیون اسکواش
- `ARCHITECTURE.md`: اصول معماری، ذخیره‌سازی، انتقال و همگام‌سازی

## پایلوت اسکواش
مرکز اسکواش فرم‌های درآمد و هزینه، بودجه و تعهدات، شناسنامه اسناد، گزارش‌ها، خروجی CSV و پشتیبان JSON دارد. داده‌های این مرکز در کلید محلی جداگانه‌ای ذخیره می‌شود و با پرونده‌های سایر فدراسیون‌ها مخلوط نیست.

## مدل بهره‌برداری فعلی
این نسخه برای نمونه‌سازی و کار محلی تک‌دستگاهی است. نقش‌ها نمایشی‌اند و LocalStorage احراز هویت یا کنترل دسترسی امنیتی ایجاد نمی‌کند. داده‌ها بین دستگاه‌ها همگام نمی‌شوند مگر بسته JSON منتقل شود. برای داده محرمانه و عملیات واقعی استفاده نشود.

## مسیر توسعه
مدل داده به‌گونه‌ای تعریف شده که قابلیت انتقال به Excel و Access را داشته باشد و بعداً با Storage Adapter به IndexedDB، SQLite، دیتابیس سرور و API متصل شود. جزئیات در `ARCHITECTURE.md` آمده است.
