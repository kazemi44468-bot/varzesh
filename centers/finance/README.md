# مرکز خدمات مالی پورتال ورزش

این پوشه شامل نمونه اولیه محلی مرکز خدمات مالی است.

## فایل‌ها
- `index.html`: رابط کاربری مرکز مالی
- `finance.css`: سبک و چیدمان واکنش‌گرا
- `finance.js`: منطق ثبت و گزارش‌گیری محلی

## امکانات نسخه محلی
- پرونده داده مستقل برای هر فدراسیون
- ثبت درآمد و هزینه و دفتر گردش مالی
- ثبت ردیف‌های بودجه و اعتبار
- ثبت مشخصات فاکتور، قرارداد و اسناد
- داشبورد تجمیعی مدیریت مرکزی
- گزارش خلاصه، ترکیب هزینه‌ها، چاپ و خروجی CSV
- پشتیبان‌گیری JSON از داده‌های مرورگر

## محدودیت امنیتی مهم
این نسخه برای طراحی گردش‌کار و استفاده آزمایشی روی یک مرورگر/رایانه است. داده‌ها در `localStorage` همان مرورگر ذخیره می‌شوند؛ بین کاربران یا دستگاه‌ها همگام نیستند. انتخاب «مدیریت مرکزی» یا «خزانه‌دار» صرفاً تغییر نمای رابط است و احراز هویت یا کنترل دسترسی امنیتی ایجاد نمی‌کند. این نسخه نباید برای اطلاعات مالی محرمانه یا عملیاتی استفاده شود.

برای بهره‌برداری واقعی باید API و پایگاه داده سمت سرور ایجاد شود و احراز هویت، نقش‌ها، انتساب هر خزانه‌دار به یک فدراسیون، کنترل مجوز در سمت سرور، ثبت رخدادهای حسابرسی، پشتیبان‌گیری امن و نگهداری اسناد پیاده‌سازی شود. کد سمت کاربر به‌تنهایی مرز امنیتی محسوب نمی‌شود.

## اجرا
فایل `index.html` را از طریق یک وب‌سرور محلی ساده باز کنید تا مسیر فونت‌های محلی پروژه نیز به‌درستی بارگذاری شود.
