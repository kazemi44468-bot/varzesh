# پورتال ورزش

وب‌سایت معرفی و ورودی زیست‌بوم یکپارچه ورزش ایران.

## دامنه‌ها
- پورتال مادر: https://varzeshportal.ir
- درگاه مستقل فدراسیون‌ها: https://fedrasionha.ir

## ساختار فعلی
- `index.html`: صفحه معرفی و ورودی اصلی پورتال
- `centers/`: صفحات آغازین حوزه‌های تخصصی
- `404.html`: صفحه خطای اختصاصی فارسی

## انتشار
این مخزن برای انتشار استاتیک روی GitHub Pages آماده شده است. برای اتصال دامنه، در تنظیمات مخزن بخش Pages دامنه سفارشی `varzeshportal.ir` را ثبت کنید و رکوردهای DNS را مطابق راهنمای GitHub Pages تنظیم کنید.

## نکته توسعه
درگاه فدراسیون‌ها به‌صورت دامنه مستقل معرفی شده است. محتوای شناسنامه فدراسیون‌ها و داده‌های رسمی باید در مرحله بعد با منابع معتبر تکمیل و راستی‌آزمایی شوند.
